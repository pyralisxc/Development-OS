# Development OS Support

Development OS is maintained in the public GitHub repository:

https://github.com/pyralisxc/Development-OS

For bugs, packaging problems, activation regressions, documentation issues, or other support requests, use:

https://github.com/pyralisxc/Development-OS/issues

When reporting a problem, include the Development OS version, the host/surface where it occurred, the expected behavior, and the smallest useful reproduction evidence.

Do **not** post passwords, API keys, private keys, MFA codes, recovery codes, access tokens, private customer data, or other secrets in a public issue. If a matter is privacy- or security-sensitive, open a minimal issue without confidential details and request an appropriate private contact path.

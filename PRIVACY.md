# Development OS Privacy Policy

**Effective date:** October 4, 2026

Development OS is a skills-only software-development methodology plugin distributed from the public `pyralisxc/Development-OS` repository. The plugin package does not include an MCP server, remote service, app ID, analytics service, or developer-operated data store.

## Data collected by the Development OS publisher

Development OS does not collect or receive personal data through the plugin itself. Installing or using the skills package does not send your prompts, files, repository contents, credentials, account profile, or usage telemetry to a Development OS-operated server.

## How data is used

The Development OS skills provide instructions that the host can apply to software-development work. The publisher does not separately process user data for advertising, profiling, sale, or unrelated analytics.

## Host and connected-service processing

Your ChatGPT or Codex host may process conversation content, files, and tool results under the host provider's own terms and privacy practices.

Development OS can be used alongside independently connected services such as source-control, deployment, code-intelligence, browser, or other provider tools. Those services are not bundled into Development OS, and their collection, use, sharing, and retention practices are governed by their own policies and by the permissions you grant them.

## Data recipients

Because the Development OS plugin does not transmit user data to a Development OS-operated service, the publisher has no plugin-collected personal data to disclose to recipients.

If you voluntarily post information in the public Development OS GitHub repository—for example in an issue or discussion—that information is handled by GitHub under GitHub's policies and may be publicly visible.

## Retention

Development OS retains no user conversation, file, repository, credential, or telemetry data through the plugin.

Information you voluntarily submit to the public GitHub repository remains subject to GitHub's retention controls and the repository's public history.

## User controls

You can stop using or uninstall Development OS at any time. You control which independent external services, if any, you connect to your host.

Do not include passwords, API keys, MFA codes, recovery codes, private keys, or other secrets in public support requests.

## Changes to this policy

Material changes to this policy will be published in the Development OS repository with normal Git history.

## Contact and support

For Development OS questions, use the public support path documented in [SUPPORT.md](./SUPPORT.md). For privacy-sensitive matters, do not post confidential information publicly; open a minimal support request asking for an appropriate private contact path.

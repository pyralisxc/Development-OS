# Development OS Terms of Use

**Effective date:** October 4, 2026

These terms apply to the Development OS skills-only plugin distributed from the public `pyralisxc/Development-OS` repository.

## What Development OS provides

Development OS provides software-development reasoning and workflow instructions for use inside a compatible agent host. It is methodology, not a hosted development service, code repository, deployment provider, credential manager, or system of record.

## No bundled remote service

The plugin package does not include a Development OS-operated MCP server or other remote backend. Independent tools and providers that you connect to your host remain separate services governed by their own terms, permissions, and policies.

## Your responsibility for development actions

Development OS is designed to preserve human authorization and consequential approval boundaries, but software-development actions can still affect code, infrastructure, deployments, data, accounts, or third-party services.

You are responsible for deciding which repositories, accounts, environments, and consequential operations you authorize. Review high-impact changes before accepting or deploying them.

## Credentials and restricted information

Do not provide passwords, private keys, MFA or recovery codes, or other authentication secrets to Development OS merely to continue a workflow. Use provider-supported authentication and permission flows.

## Availability and changes

Development OS may change over time as the methodology is tested and improved. Versions are identified in the plugin package and repository history.

The plugin is provided on an as-available basis. No guarantee is made that every host, model, connected service, or user interface will behave identically across versions.

## Third-party services
